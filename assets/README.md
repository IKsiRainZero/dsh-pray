# Realm 5 image

The fifth realm is an image supplied by the project owner.

- Put the screenshot at `assets/realm-5.png` (JPG/JPEG/WebP are also served).
- The Host route `/dsh-pray/asset/realm-5` serves the first available of `realm-5.png` / `.jpg` / `.jpeg` / `.webp`, then `realm-5.svg`.
- `realm-5.svg` is a placeholder and can stay as the fallback.
- Make sure you have the right to share the image publicly.
