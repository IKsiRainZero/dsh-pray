# dsh-pray · 期待

> 一个本地单机的 DeepSeek Harness 增量小游戏：五层 **Level**、**愿力**、**催更**、**发版**、**释怀**，以及**注意力保护模式**。
>
> 无账号、无排行榜、无总仓库、无遥测；所有数据都在本机 `$DSH_HOME/dsh-pray/`。

**v0.4.1 hotfix**：Level 1 的每 10 个成本倍率从 ×100 提到 ×1e3（后续层 1e4~1e7），修掉注意力保护模式自动购买跑飞的问题；自动购买在“可释怀”时会暂停。若旧存档数值已经异常，设置页有 **重开本轮**（保留愿力、释怀、成就、档案）和 **修复存档**（释怀倍率归零，保留愿力、成就、档案）。

## 先说清楚：它不想要你的注意力

- 第一次打开会弹一次说明：这是一个本地单机小游戏，不是待办，也不催你。
- 默认 **注意力保护模式**：自动买 Level 和本轮增幅器，不自动催更/发版/释怀；右下角卡片默认隐藏。
- 想看时从侧栏「期待」打开；设置里可以随时切到 **游玩模式**，手动购买。
- 右下角卡片可以完全收起：`−` 收成小胶囊，`×` 隐藏；隐藏后在设置里恢复。
- 只读会话数、完成轮数、活跃时长这些数字，不读聊天内容。

## 五层 Level

| Level | 名字 | 解锁（累计期待） | 基础成本 | 每 10 个成本倍率 | 产出 |
|---|---|---|---|---|---|
| 1 | 期待下次更新 | 0 | 1 | ×100 | 期待 |
| 2 | 别打扰梁叔叔搞AGI | 1,000 | 10 | ×1e3 | Level 1 |
| 3 | 谁给ds报名的憋气大赛？ | 100,000 | 1,000 | ×1e4 | Level 2 |
| 4 | Pro来✋🏻😡🤚🏻 | 10,000,000 | 1e5 | ×1e5 | Level 3 |
| 5 | 我们的deepseek···会变成什么样子 | 1,000,000,000 | 1e7 | ×1e6 | Level 4 |

所有 Level 始终列在 Level 页里：左边的编号是递进，中间是拥有量 / 已买 / 本层累计产出 / 购买增幅 / 速度，右边是 +1 / +10 / MAX。锁定 Level 也会显示，只是变暗。

## 催更 / 发版 / 释怀

| 层 | 动作 | 代价 | 重置 | 留下 |
|---|---|---|---|---|
| 1 | **催更** | 期待，首价 10,000，×100/次 | 所有 Level、本轮增幅器 | 催更次数（×1.5 全局/次）、本轮累计、愿力 |
| 2 | **发版** | 3 + 已有发版次数 次催更，外加期待（首价 1e6，×100/次） | 催更、所有 Level、本轮增幅器 | 发版次数（×2 全局/次）、本轮累计、愿力 |
| 3 | **释怀** | 本轮累计期待 ≥ **1e12** | 期待、Level、催更、发版、本轮增幅器 | 愿力、释怀、永久增幅、档案、Level 累计产出 |

- 释怀获得 `floor(sqrt(本轮期待 / 1e12))` 点释怀；每点永久 +10% 全局产出。
- 1e12 的门槛在 Level 5 解锁（1e9）之后还要再走一段，避免“刚解锁就释怀”。
- 催更/发版/释怀都要求二次确认；第一次释怀有全屏特效，设置页可预览。
- 提示：你已经有一次 v0.2 时代的释怀记录（`release=1`），所以永久倍率是 ×1.1；新门槛只影响下一次。

## 愿力（行为货币）

只来自行为，不跟钱/token 花费挂钩：

- 新开一个用户根会话 +1；每日首个会话额外 +3；
- 完成一轮 +1；
- 每活跃 10 分钟 +1；
- 连续天数 +1~5/天；
- 子 agent 只统计“分身”，不给愿力；
- token 与成本只进档案，不做货币；
- 每日上限 30（永久增幅可加）。

永久增幅器：专注（期待 +10%/级）、回声（愿力 +5%/级、上限 +5/级）、挂机（离线上限 +2h/级）。

## 故事与成就

- **故事** 页按 Level 解锁五章：期待下次更新 / 别打扰梁叔叔搞AGI / 谁给ds报名的憋气大赛？ / Pro来✋🏻😡🤚🏻 / 我们的deepseek···会变成什么样子。
- **成就** 是本地永久小倍率，例如第一次释怀、解锁 Level 3/5、10 个会话、100 轮、连续 7 天、10 次催更、3 次发版；不要求花钱。
- **纪事** 自动记录 DeepSeek 更新日志的日期与标题；版本红利给 24h ×1.5。

## 数据与隐私

| 文件 | 内容 |
|---|---|
| `$DSH_HOME/dsh-pray/state.json` | 期待、Level、催更、发版、愿力、释怀、成就、档案、更新日志缓存、纪事 |
| `$DSH_HOME/dsh-pray/aggregate.json` | **v0.1 遗留**，v0.4 不再读写；可手动删除 |

- 只监听 DSH 核心事件：`session/created`、`session/event`、`session/disposed`。
- 只存数字聚合：会话数、完成轮数、活跃秒数、连续天数、工具调用数、token 数；不存 prompt、回复、文件路径、账号或密钥。
- 除抓取官方更新日志外，不联网、不上传、不读 `dsh-context` 的数据库。
- 设置页提供「导出本地数据」；删除 `$DSH_HOME/dsh-pray/` 即可清空本地数据。

## 安装

### 从 GitHub 安装（当前推荐）

仓库：<https://github.com/IKsiRainZero/dsh-pray>

```sh
dsh plugin --profile <profile> add github:IKsiRainZero/dsh-pray
```

本插件没有构建脚本；装完重启 profile 即可。

### 发布后（npm）

```sh
dsh plugin --profile <profile> add dsh-pray
```

## 开发

- 纯 JS，无构建步骤；Host 只用 Node 内置模块，Client 只用 `window.__ModuleLoader__` + React。
- 数值表：`game/balance.js`；纯函数引擎：`game/engine.js`；行为采集：`game/activity.js`。
- 测试：`node test-engine.mjs`、`node test-host.mjs`。

## 已知限制

- **v0.3 → v0.4 迁移**：`boosts/galaxies` → `urges/launches`；`settings.mode` 默认 `attention`；Level 5 改成文字，不再使用图片。
- **v0.2 → v0.4**：三维度 A/B/C 映射到 Level 1/2/3；旧 `dimA/B/C` 增幅器映射到 `level1/2/3`。
- **v0.1 → v0.4**：旧 `points` 变成 `expectation` / `lifetimeExpectation`；旧 `aggregate` / `lastPushAt` 忽略。
- **档案是自安装以来**：`sessions.list()` 只有 live 会话，不做历史日志全量回填。
- **没有反作弊**：本地 JSON 可改，开源即接受。
- **数值仍在调**：催更/发版门槛、释怀 1e12、每日愿力上限都可能随体验调整。

## 兼容性

- 当前验证环境：DSH Desktop `0.2.1-rc.3`，profile `desktop`，Web GUI。
- `engines.dsh`: `>=0.2.1-rc.1 <0.3.0-0`。
- 上游每发一个新的 `0.x.y` 元组，需要重新核对 semver range。
